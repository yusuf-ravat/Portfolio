A modern, high-performance personal portfolio website built with clean vanilla web standards (HTML5, modern CSS3, ES6+ JavaScript), featuring **cyber-glassmorphism**, **real-time particle canvas effects**, an **interactive AI CLI terminal simulator**, and **in-depth project case-study modals**.

---

## ✨ Features

- 🌌 **Cyber Glassmorphism UI:** Deep obsidian aesthetic with dynamic ambient gradients and translucent cards.
- 🎨 **Multi-Theme Accent Switcher:** Real-time theme switching (Cyber Cyan, Violet Nebula, Emerald Matrix, Sunset Flare) with `localStorage` persistence.
- ⚡ **Interactive Particle Canvas:** Lightweight physics-driven background particle grid responding dynamically to viewport sizing.
- 🤖 **Interactive AI Assistant Terminal:** Built-in CLI simulator allowing visitors and recruiters to interactively query skills, projects, background, and contact details with command suggestions.
- 💼 **Comprehensive Case-Study Modals:** Detailed architecture breakdowns and engineering responsibilities for flagship SaaS platforms and enterprise applications.
- 📱 **Fully Responsive & Accessible:** Optimized for seamless performance across mobile, tablet, and ultra-wide displays.
- 🔍 **SEO & Social Graph Optimized:** Integrated Open Graph tags, Twitter Cards, and Schema.org (`Person`) JSON-LD structured data for rich Google search indexing.

## 🚀 Getting Started Locally

No complex dependencies or build tools required. You can run the portfolio locally using any static web server:

### Option 1: VS Code Live Server
1. Open the project folder in **VS Code**.
2. Right-click [`index.html`](index.html) and select **"Open with Live Server"**.

### Option 2: Python HTTP Server
```bash
# Python 3
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.
